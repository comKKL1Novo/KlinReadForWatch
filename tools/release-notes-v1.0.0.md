# KlinRead for Watch v1.0.0

数据层与手机版同步，UI 针对小屏和圆屏调整。

## 本次更新

### 界面：Apple 风格设计系统

- **中性色改用 Apple 系统灰**：浅色 `#F2F2F7` 页面 + 纯白卡片，深色 `#1C1C1E` 页面 + `#333336` 卡片。之前页面与卡片亮度只差 5%，卡片几乎看不见。
- **强调色保留粉色**（`#8E2A5E`）。
- **8pt 网格**、**负字距**（标题 -0.022em、正文 -0.011em）、**圆角** 8/12/16。
- **按下反馈**：可点元素按下缩放到 0.96。

### 书架改为封面网格

从竖向列表改成 **2 列封面网格**。手表屏幕窄，3 列会让每本封面只有约 100px，比原来的缩略图还小，所以用 2 列。封面按 2:3 书籍比例，进度条叠在封面底边。

### 分类精简

去掉「未分类」chip —— 它回答的是「有没有设置自定义分类」，和「未读/在读/读完」是两回事，混在一行让人困惑。现在只有 全部 / 未读 / 在读 / 读完 + 自定义分类。

### 阅读位置记录重做

原本只记录章节序号，导致：
- 读到第 1 章任何位置都显示 0%
- 重新打开书总是回到章节开头

现在记录**实际所在段落的字符偏移**，打开时按段落恢复。

同时修了一个隐蔽的问题：位置写入原本在 `onDispose` 里用 `viewModelScope` 发起，而那时 ViewModel 正在被销毁，协程被取消，写入根本没落盘。

## 本版修复

- **中文 TXT 打不开**：格式嗅探的 4096 字节窗口切在中文（3 字节/字）中间导致校验失败，报「无法识别的文件格式」。现已对齐到字符边界。
- **文件重复打开**：解析一本书要开 2–3 次 URI，部分文件管理器只给短暂授权。现改为只打开一次。EPUB 仍保持两遍流式读取以控制内存。
- **音乐失效音轨静默失败**：源文件删除后点击播放无反应。现在明确提示，并加准备超时兜底。

## 安装

```powershell
adb install -r app-armeabi-v7a-release.apk
```

- `app-armeabi-v7a-release.apk` —— OPPO Watch（OWW212）等 32 位手表用这个
- `app-arm64-v8a-release.apk` —— 64 位手表
- `app-universal-release.apk` —— 不确定架构时使用

## 已知问题

**EPUB 阅读进度识别有误** —— 进度条和「未读 / 在读 / 读完」可能与实际读到的地方不符。书架顶部有提示条标注，下个版本修复。

## 已知限制

- **数据库结构变更不迁移**：升级会重建数据库，书架需要重新导入。
- **封面提取的格式覆盖有限**：MOBI 只按「第一张图片」定位；TXT / HTML / UMD 一律使用生成的占位图。
